# Checklist: 10 Elementos de um Cupom que Converte

Use este checklist antes de publicar cada CupomClic para garantir máxima conversão.

---

## ✅ ELEMENTOS OBRIGATÓRIOS

### 1. Foto de Alta Qualidade
- [ ] Foto clara, bem iluminada
- [ ] Produto em destaque (sem bagunça ao redor)
- [ ] Múltiplos ângulos se possível
- [ ] Resolução mínima: 1080x1080px

### 2. Nome Específico do Produto
- [ ] Inclui cor, tamanho, modelo
- [ ] Evita termos genéricos ("camisa" → "Camisa Social Azul Marinho M")
- [ ] Máximo 60 caracteres

### 3. Preço Original Visível
- [ ] Preço cheio claramente mostrado
- [ ] Formato: R$ 149,90 (com vírgula e dois decimais)
- [ ] Sem arredondamentos confusos

### 4. Desconto Atraente
- [ ] Mínimo 15-20% de desconto
- [ ] Valor do desconto claramente destacado
- [ ] Mostra economia real (ex: "Economize R$ 30")

### 5. Prazo de Validade Curto
- [ ] Validade entre 3-7 dias
- [ ] Data de expiração claramente visível
- [ ] Cria senso de urgência real

### 6. Quantidade Limitada
- [ ] Estoque limitado definido (ex: 50 unidades)
- [ ] Mostra unidades restantes quando possível
- [ ] Escassez real, não inventada

### 7. Descrição Persuasiva
- [ ] Foca no benefício, não na característica
- [ ] Usa gatilhos mentais (escassez, urgência, prova social)
- [ ] Máximo 3-4 linhas
- [ ] Inclui chamada para ação

### 8. Link Funcional
- [ ] Testou o link antes de divulgar
- [ ] Link abre corretamente no celular
- [ ] Processo de compra funciona do início ao fim

### 9. Canal de Distribuição Definido
- [ ] Escolheu onde vai divulgar (Instagram, WhatsApp, live, etc.)
- [ ] Link formatado para o canal escolhido
- [ ] Horário de postagem estratégico

### 10. Plano de Acompanhamento
- [ ] Sabe onde verificar os resultados
- [ ] Definido quando vai analisar as métricas
- [ ] Preparado para ajustar se necessário

---

## 📊 MÉTRICAS PARA ACOMPANHAR

Após publicar o cupom, monitore:
- **Cliques no link:** Quantas pessoas clicaram
- **Taxa de conversão:** % que clicou e comprou
- **Faturamento:** Valor total vendido
- **Produto mais vendido:** Qual item performou melhor

## 🎯 META MÍNIMA

Um cupom bem otimizado deve ter:
- Taxa de conversão mínima: 5-10%
- Retorno sobre investimento: 3x o valor do desconto oferecido
