# Tutorial: Criando seu Primeiro CupomClic

Guia passo a passo para criar seu primeiro link de vendas em menos de 5 minutos.

---

##  PASSO A PASSO COMPLETO

### 1. Acesse a Plataforma Tokto
- Abra o app Tokto no seu celular ou computador
- Faça login com sua conta de lojista
- No menu principal, clique em **"Criar CupomClic"**

### 2. Cadastre o Produto
- **Foto:** Tire uma foto clara do produto (luz natural, fundo limpo)
- **Nome:** Seja específico (ex: "Camisa Social Azul M" em vez de "Camisa")
- **Preço Original:** Valor cheio do produto (ex: R$ 149,90)
- **Preço com Desconto:** Valor após o cupom (ex: R$ 119,90)

### 3. Configure o Cupom
- **Tipo de Desconto:** Percentual (ex: 20%) ou valor fixo (ex: R$ 30)
- **Validade:** Defina prazo curto (3-7 dias) para criar urgência
- **Quantidade:** Limite de usos (ex: 50 unidades) para escassez real
- **Descrição:** Texto persuasivo focado no benefício

### 4. Gere o Link
- Clique em **"Gerar Link CupomClic"**
- O link único será criado automaticamente
- Copie o link para usar onde quiser

### 5. Distribua o Link
- **Instagram:** Cole na bio, story com link, legenda de post
- **WhatsApp:** Envie em mensagens diretas, listas de transmissão, status
- **Live:** Fixe o link no chat durante a transmissão
- **E-mail:** Inclua no corpo do e-mail marketing

### 6. Acompanhe os Resultados
- Acesse o painel **"Meus Cupons"**
- Veja quantas vezes o link foi clicado
- Monitore a taxa de conversão (clique → venda)
- Identifique o produto mais vendido

---

## 💡 DICAS IMPORTANTES

✅ **Teste antes de divulgar:** Clique no seu próprio link para garantir que está funcionando
✅ **Use links curtos:** O CupomClic já gera links otimizados para compartilhamento
✅ **Atualize frequentemente:** Crie novos cupons a cada semana para manter o engajamento
✅ **Responda rápido:** Quando o cliente comprar, confirme o recebimento imediatamente
